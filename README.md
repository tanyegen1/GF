# Doga & Tan 💕

A single-page couples app, built as a gift. Hearts float everywhere in the
background, the big logo heart holds the initials **"DT"**, and the whole
thing is rigged in the most loving way possible: no matter what you pick in
the "Who Loves More?" quiz, the universe always concludes that **Tan loves
more**.

## Features

- **Hearts-everywhere theme** — animated floating hearts in the background,
  some carrying a subtle "DT" watermark, plus a big pulsing "DT" heart logo.
- **Character select** — choose **Doga** (girl side) or **Tan** (boy side)
  to personalize the greeting.
- **"Who Loves More?" quiz** — 8 playful questions with 4 options each.
  Every option leads to a different witty response, but the final result is
  always a scientifically-confirmed **Tan loves more** 🎉 with a confetti
  heart burst and an animated percentage counter.
- **Our Days Together** — set your relationship start date once (saved
  locally in the browser) and watch a live day/hour/minute/second counter.
- **Love Notes** — a button that reveals a random sweet/funny reason "Tan
  loves Doga."
- **Love Fortune** — a little fortune-cookie style romantic prediction
  generator.
- **Love Meter** — drag the slider to try to tip the scale; it always snaps
  back to Tan loving (almost) 100%.
- **Secret Letter** — a typewriter-animated love letter from Tan to Doga.
- A tiny heart pops wherever you click/tap, for fun.

Everything is a single self-contained `index.html` file — no build step, no
dependencies beyond a Google Fonts link. You can just open it in a browser,
or host it anywhere static (GitHub Pages, Netlify, etc.).

## Running locally

Just open `index.html` in any browser. That's it.

## Hosting it on GitHub Pages (free, public link)

This repo doesn't have Pages enabled yet (that's a one-time setting only a
repo owner can toggle). To get a live `https://<you>.github.io/<repo>/`
link:

1. Go to the repo on GitHub → **Settings** → **Pages**.
2. Under "Build and deployment", set **Source** to **Deploy from a branch**.
3. Pick the branch with this code (e.g. `claude/determined-bell-856pd8`, or
   `main` once merged) and folder `/ (root)`, then **Save**.
4. After a minute, your link will be live at the URL GitHub shows on that
   page.
